# Setup

1. Install Node.js 22 and Android Studio.
2. From the repository root run `npm install`.
3. Copy `.env.example` to `.env` and set a random JWT secret.
4. Run `npm run typecheck`, `npm test`, and `npm run build`.
5. Start the signaling service and Vite dashboard.
6. Build/install the Android app in Android Studio.
7. Test first on one local network, then test across cellular/Wi-Fi using HTTPS/WSS and TURN.

Browser downloads are controlled by browser settings; PocketCam does not promise a particular Windows folder.
